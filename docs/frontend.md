# Рабочий frontend REA Auction

Ветка: `dev_any`. Реализация на React + TypeScript + Ant Design, интеграция с существующим Django REST API.

## Страницы

| Маршрут | Назначение | Требуется авторизация |
| --- | --- | --- |
| `/`, `/design-preview` | Обучающий макет обратного аукциона и лестница ставок | Нет |
| `/login` | Вход через Django session + CSRF | Нет |
| `/auctions` | Каталог, фильтры, поиск, пагинация | Да |
| `/auctions/:id` | Детали, собственная ставка, результат, отправка/модерация по роли | Да |
| `/auctions/new` | Создание задачи с idempotency key | Да |
| `/auctions/:id/edit` | Редактирование черновиков и отклонённых задач | Да |
| `/cabinet` | Собственные задачи по статусам | Да |
| `/profile` | Достоверная информация из `/api/auth/me/`, ссылки на действия | Да |
| `/moderation` | Очередь модерации и переход к решениям | Только модератор |

## Запуск полноценного приложения

В корне проекта запустите Django, PostgreSQL и обработчик закрытия торгов согласно README проекта, затем:

```bash
cd frontend
npm ci
npm run dev
```

Vite проксирует `/api` на `http://localhost:8000`.

## Ограничения публикации

**GitHub Pages запускает только статический frontend, не Django и не PostgreSQL.**
Публичный адрес `https://mivolasdormijj.github.io/REA_auction/` показывает обучающий макет. Маршруты пользовательского кабинета/входа входят в сборку, но настоящая авторизация, каталог, создание задач, ставки и модерация **не будут работать онлайн**, пока API не размещён на сервере с корректно настроенными cookies/CSRF и маршрутизацией.

Не показывайте демонстрационные ставки как реальные. Сервер раскрывает каждому пользователю лишь собственные ставки, а итог определяется второй ценой. Нельзя добавлять на frontend отображение чужих ставок без изменения модели доступа и согласования правил аукциона.

Текущие `/auth/me/` и `/auth/login/` отдают `id`, `username` и `can_moderate`. Сервер не предоставляет редактирование профиля, регистрацию через веб-интерфейс или общий список своих ставок, поэтому эти функции намеренно **не имитируются**. Для них понадобятся отдельные серверные API и тесты.
